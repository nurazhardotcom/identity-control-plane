# Security Policy

## Supported Versions

| Version       | Supported |
| ------------- | --------- |
| latest `main` | yes       |
| older tags    | no — please upgrade and re-test |

## Reporting a Vulnerability

Open a private security advisory via the repository's **Security** tab.
Do not file public issues for suspected vulnerabilities.

Include: affected file/commit, reproduction steps, and impact assessment.
Expect an initial response within 7 days.
